# knights-travails

Knights Travails is a simple function that tracks the most efficient path in a chessboard for a knight.

Tools used:

- JavaScript
- Jest
- Babel (for Jest compatibility)
- Prettier (VSCode ext.)

## Feature:

1. `knightMoves(start, end)`;

## Things I learned:

1. Applying Breadth First Search.
2. Graphs.

### How to use

1. Clone using this command: git clone `https://github.com/SuspiciousApplePie/knights-travails.git`.
2. Install Jest: npm install --save-dev jest.
3. Install Babel: npm install --save-dev @babel/preset-env.
4. Done.
